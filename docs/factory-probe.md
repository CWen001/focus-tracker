# 工厂离线规则验证

当前工厂未启用自动接单。本页描述离线探测，不是完整工厂使用说明。

运行以下命令验证任务领取和结果关联。测试使用临时 SQLite、虚构事件和合成证据，不采集桌面活动，也不访问 GitHub。

```sh
python -B -m unittest discover -s tests -p test_factory_gate.py -v
```

`tools/factory_gate.py` 将 Ticket、Run 和返修次数保存在本地 SQLite。每个调用使用独立连接，领取通过事务和唯一索引限制为一个在途 Run。重开连接不会清除计数。三个返修机会用完后再次失败，Ticket 停在 blocked。成功依次经过 implement、verify、review，最后停在 human，不合并。

授权函数接收调用者提供的可信 API 快照。它检查固定仓库及作者账号 ID。第三方 Ticket 需要作者身份为仓库所有者的 `/approve` 评论。评论必须未编辑，并且创建时间严格晚于 Ticket 当前更新时间。同秒事件拒绝，不猜测先后。修改后的范围不能继续旧 Run。`finish` 要求调用者再次提供当前 Ticket 和评论。

证据必须包含当前 Run ID、阶段、提交 SHA 和 pass 或 fail。实现结果可以给出新提交，验证和审查必须匹配该提交。缺文件、错 Run、错阶段或旧 SHA 不推进状态。已领取但未报告结果的 Run 保持占用。`interrupt` 把它标为 unknown，并阻止再次领取，直到未来的人工核对流程解决不确定性。

## 尚未证明的部分

此模块不验证 API 来源，不启动代理，不判断证据是否真实，也不证明审查者独立。调用者伪造可信输入仍能伪造结论。它不能直接作为生产入口。缺少可信 GitHub 接入、独立工作 Run、实际模型进程取消与恢复、证据复核和 unknown 的人工核对流程。

SQLite 规则探测不代替原版 orch 的 Windows 恢复验收。原版并发恢复目前仍阻塞。没有轮询服务、后台自动 Trigger、安装、开机自启或自动合并。

真实 Chrome 扩展、五分钟空闲、播放保护和锁屏睡眠需要单独的授权及真实环境验证。单元测试和本地证据报告截图均不证明这些行为。既有 CLI 生命周期记录是此前授权的历史证据，不自动成为新提交的实测证明。
