# 验证范围

这是开发基线，不是发布就绪或完整软件工厂的证明。候选提交的实际检查结果与独立静态审查会记录在对应 PR，并绑定提交 SHA。

## 可复跑检查

仓库根目录运行 README 中的 Python unittest 与三个 Node 测试。Python 测试涵盖 CLI 的无副作用检查、模拟 Windows 会话事件、真实随机互斥体和本地管道、消息校验、时间线、SQLite 原子提交与重试、安装预览及模拟注册表、保存字段白名单和虚拟长时间线。

`tests/browser/playback.html` 使用真实 Chrome 媒体 API 和合成内容，不访问日常浏览页面。页面 Run checks 成功不证明扩展、原生桥、桌面采集器与数据库已完成真实集成。

这些检查不安装扩展，不执行实际注册表安装，不采集用户活动。安装测试的注册表对象为替身。

## 未完成的系统验收

- 启动时会话状态、锁屏/休眠及恢复的受控实测。
- Chrome 扩展到 Native Messaging、本机管道、SQLite 和 status 的完整连接；关闭和重启 Chrome 后的状态恢复。
- 至少 30 次受控应用与标签切换的时间误差。
- 多窗口、多配置、跨域视频、画中画、桌面播放器及受限页面的支持边界。
- .cmd 原生桥由 Chrome 启动及控制台闪窗情况。
- 独立网络观测。源码检查与禁止网络的合成测试不是运行时无外传证明。
- 真实 8 小时的 CPU、内存、存储增长、异常退出及恢复。
- 跨用户/会话及远程客户端对管道的实际拒绝测试。当前 ACL 断言不能替代全部攻击路径检查。

验证不应读取或上传个人历史。公开证据只使用合成数据和去标识的摘要。未知、受阻和失败不得写成通过。
